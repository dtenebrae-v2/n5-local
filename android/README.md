# N5 Local для Android

Личная автономная сборка: Android WebView + встроенный Python 3.14 (Chaquopy).
Интерфейс и HTTP API используются из основного проекта. Сервер слушает только
`127.0.0.1:8095`; компьютер и доступ в интернет для занятий не нужны.

Поддерживаемая архитектура — ARM64, минимальная версия Android — 8.0.
Основное целевое устройство — Samsung Galaxy S26 Ultra с Android 17.

## Содержимое

В APK включаются `server.py`, модули `n5`, весь `static` и `data`, в том числе
материалы из Git: Tadoku, Sō-matome и экзамены JLPT.
Перед упаковкой проверяются наличие и SHA-256 всех файлов из каталогов.
Отсутствие или повреждение материала останавливает сборку.

Материалы остаются личными: APK содержит частные учебные файлы и не предназначен
для публикации. Указания авторства и лицензий сохраняются в интерфейсе и каталогах.

## Сборка

Нужны полный JDK 17 (с `javac`), Python 3.11+ и Android SDK (platform 35,
build-tools 35.0.0). Для предварительной компиляции Python-кода Chaquopy
рекомендуется также Python 3.14; встроенный Python приложения остаётся 3.14.
Gradle 8.11.1 загружается автоматически через wrapper. Первая сборка требует
интернета для зависимостей. Укажи `ANDROID_HOME` и `JAVA_HOME`, затем из этой папки:

```sh
./gradlew assembleDebug
```

Устанавливаемый подписанный тестовый APK:
`app/build/outputs/apk/debug/app-debug.apk`.
Для обновлений с сохранением данных нужно использовать тот же ключ подписи
(`~/.android/debug.keystore` для стандартной debug-сборки). Сохрани его резервную
копию. Для долговременной версии рекомендуется отдельный постоянный release-ключ.

Проверка упакованного приложения на машине сборки:

```sh
python3 ../scripts/check_android_bundle.py app/build/generated/n5-assets
```

Проверка проверяет сам архив и запускает его содержимое в отдельной временной
папке: API, все книги/аудио/изображения с Range-запросами и отдельный словарь.
Она не заменяет проверку WebView и клавиатуры на Android-устройстве.

## Первый запуск и данные

При первом запуске материалы распаковываются во внутреннее хранилище приложения.
Для установки и распаковки желательно иметь не менее 2 ГБ свободной памяти.
При следующих запусках повторная распаковка не требуется, если комплект не менялся.
Новые комплекты распаковываются отдельно от предыдущего.

Словарь с добавленными словами находится отдельно от материалов. Прогресс хранится
в хранилище WebView с постоянным адресом, поэтому обычные обновления APK его
сохраняют. Очистка данных или удаление приложения удаляют личный прогресс и слова.
Данные из браузера настольного компьютера автоматически не переносятся.

Кнопка Android «Назад» возвращает предыдущую страницу или закрывает полноэкранный
просмотр. CSV и оригиналы книг сохраняются через системный диалог выбора файла.
Ссылки на внешние источники открываются в браузере.

Просмотрщик книг поддерживает непрерывную прокрутку, увеличение двумя пальцами
вокруг выбранного фрагмента, миниатюры и восстановление позиции внутри страницы.
Панель аудио остаётся доступной при прокрутке. Жесты PDF обрабатываются просмотрщиком;
встроенное масштабирование WebView также включено для остального интерфейса.
