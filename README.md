# N5 Local

Локальный словарь японского языка с грамматикой и проверкой форм. Работает без внешних сервисов.

## Запуск

```sh
docker compose up -d --build
```

Открыть `http://localhost:8095` или `http://<IP сервера>:8095` с другой машины.
`N5_PORT` меняет порт, `N5_HOST=127.0.0.1` ограничивает доступ текущим компьютером.

## Словарь

Кнопка «Добавить слово» открывает форму. Поля со звёздочкой обязательны; группа зависит от раздела. Новое слово также появляется в общем словаре.

В Docker словарь хранится в volume `vocabulary`, файл `/app/storage/vocabulary.json`. При первом запуске он заполняется из встроенного словаря. Перезапуск и пересборка сохраняют изменения; `docker compose down -v` удаляет volume. Последующие обновления встроенного словаря не перезаписывают сохранённый.

Без Docker:

```sh
python server.py
```

По умолчанию используются `127.0.0.1:8095` и `data/vocabulary.json`. Переменные `HOST`, `PORT`, `N5_VOCABULARY` меняют адрес и путь к словарю.

## Проверки

Ручное обновление Docker и сборка APK одной командой описаны в
[docs/automation.md](docs/automation.md).

```sh
python -m n5.vocabulary validate
python -m unittest -q test_server.py test_repository.py test_store.py
npm run test:forms
npm run test:ui
```

Для браузерных тестов нужны Playwright и Chromium: `npm install`, `npx playwright install chromium`.

Библиотека Tadoku использует оригинальные файлы из `data/materials/tadoku/files`, подключённые в Docker отдельно от образа. Восстановить недостающие файлы выбранного каталога:

```sh
python scripts/import_tadoku.py --download
```

Книги открываются с непрерывной вертикальной прокруткой. Доступны увеличение двумя
пальцами, кнопки масштаба до 400%, режимы «По ширине» и «Страница целиком», миниатюры
и полноэкранное чтение. Позиция внутри страницы, масштаб и место в аудио сохраняются
для каждой книги. Плеер закреплён под страницами; перемотка — по 10 секунд.
Авторы, лицензии, оригинальные PDF и отметка «Прочитано» доступны через «О книге».
Нумерация соответствует страницам PDF, включая обложки и служебные страницы.
Импорт обновляет этот счётчик при наличии `pdfinfo` (Poppler). Поиск и выделение
текста в просмотрщике не включены.

PDF сохраняются без изменений с авторством и CC BY-NC-ND 4.0. У аудио отдельно записаны источник, чтец и правообладатель; официальные загрузки предназначены для личного учебного прослушивания, а не для публичного переиздания. Файлы книг и записей не включаются в Git и Docker-образ.

Материалы разделены по источникам: `data/materials/tadoku/` и `data/materials/somatome/n5-2017/`. В Docker вся папка подключается только для чтения; `N5_MATERIALS_DIR` меняет её путь. Личный набор Sō-matome (`workbook.json`, `images/`, `audio/`) исключён из Git и образа: сохраняйте его отдельной резервной копией. Аудио восстанавливается командой `python scripts/import_somatome.py --download`.

Экзаменационные варианты находятся в `data/materials/jlpt/<набор>/` (`exam.json`, `images/`, `audio/`), также вне Git и образа. Сохраняйте всю папку отдельно. Из резервной копии проверенного манифеста и исходных PDF/OPUS набор восстанавливается через `python scripts/import_exams.py --source <исходники> --manifest <exam.json> --destination data/materials/jlpt/<набор>`; нужны Poppler и ffprobe.
