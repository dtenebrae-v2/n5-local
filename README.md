# N5 Local

Локальный словарь японского языка с грамматикой и проверкой форм. Работает без внешних сервисов.

## Запуск

```sh
docker compose up -d --build
```

Открыть `http://localhost:8095` или `http://<IP сервера>:8095` с другой машины.
`N5_PORT` меняет порт, `N5_HOST=127.0.0.1` ограничивает доступ текущим компьютером.

## Словарь

Кнопка «Добавить слово» открывает форму. Поля со звёздочкой обязательны; группа зависит от раздела. Новое слово также появляется в общем словаре.

В Docker словарь хранится в volume `vocabulary`, файл `/app/storage/vocabulary.json`. При первом запуске он заполняется из встроенного словаря. Перезапуск и пересборка сохраняют изменения; `docker compose down -v` удаляет volume. Последующие обновления встроенного словаря не перезаписывают сохранённый.

Без Docker:

```sh
python server.py
```

По умолчанию используются `127.0.0.1:8095` и `data/vocabulary.json`. Переменные `HOST`, `PORT`, `N5_VOCABULARY` меняют адрес и путь к словарю.

## Проверки

GitHub Actions → **Release builds** собирает Android ARM64, Linux x86-64/ARM64 и
Windows x86-64. Ручной запуск сохраняет файлы в Artifacts; отправка тега `v…`
собирает все платформы и прикладывает архивы, APK и SHA-256 к GitHub Release.
Для APK один раз задай Secrets: `N5_KEYSTORE_BASE64`, `N5_STORE_PASSWORD`,
`N5_KEY_ALIAS`, `N5_KEY_PASSWORD`. Используй прежний ключ подписи, чтобы APK
устанавливался поверх существующего приложения. Ключ в Git не добавляется.

Настольный архив нужно распаковать целиком и запустить `n5-local` или
`n5-local.exe`. Интерфейс откроется в браузере, Python устанавливать не нужно.
Окно запуска остаётся открытым до завершения работы (Ctrl+C). Словарь хранится
отдельно: `%LOCALAPPDATA%/N5Local` в Windows и
`${XDG_DATA_HOME:-~/.local/share}/n5-local` в Linux. Адрес остаётся
`http://127.0.0.1:8095`, поэтому прогресс браузера сохраняется при обновлении.

Ручное обновление Docker и сборка APK одной командой описаны в
[docs/automation.md](docs/automation.md).

```sh
python -m n5.vocabulary validate
python -m unittest -q test_server.py test_repository.py test_store.py
npm run test:forms
npm run test:ui
```

Для браузерных тестов нужны Playwright и Chromium: `npm install`, `npx playwright install chromium`.

Библиотека Tadoku использует оригинальные файлы из `data/materials/tadoku/files`, подключённые в Docker отдельно от образа. Восстановить недостающие файлы выбранного каталога:

```sh
python scripts/import_tadoku.py --download
```

Книги открываются с непрерывной вертикальной прокруткой. Доступны увеличение двумя
пальцами, кнопки масштаба до 400%, режимы «По ширине» и «Страница целиком», миниатюры
и полноэкранное чтение. Позиция внутри страницы, масштаб и место в аудио сохраняются
для каждой книги. Плеер закреплён под страницами; перемотка — по 10 секунд.
Авторы, лицензии, оригинальные PDF и отметка «Прочитано» доступны через «О книге».
Нумерация соответствует страницам PDF, включая обложки и служебные страницы.
Импорт обновляет этот счётчик при наличии `pdfinfo` (Poppler). Поиск и выделение
текста в просмотрщике не включены.

PDF сохраняются без изменений с авторством и CC BY-NC-ND 4.0. У аудио отдельно записаны источник, чтец и правообладатель; официальные загрузки предназначены для личного учебного прослушивания, а не для публичного переиздания.

Весь `data/materials/` включён в Git: Tadoku, Sō-matome и экзаменационные варианты вместе с PDF, изображениями, аудио и разметкой. После клонирования репозитория отдельное скачивание материалов не требуется. Git LFS не используется. В Docker папка подключается только для чтения и не копируется в образ; `N5_MATERIALS_DIR` меняет её путь. APK включает материалы при сборке. Условия использования и авторство сохраняются в каталогах источников.

Экзаменационные варианты находятся в `data/materials/jlpt/<набор>/` (`exam.json`, `images/`, `audio/`). Для повторного импорта из исходных PDF/OPUS можно использовать `python scripts/import_exams.py --source <исходники> --manifest <exam.json> --destination data/materials/jlpt/<набор>`; нужны Poppler, Pillow и ffprobe. Обычная сборка использует готовые изображения из Git.
