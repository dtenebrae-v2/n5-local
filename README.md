# N5 Local

Локальный словарь японского языка с грамматикой и проверкой форм. Работает без внешних сервисов.

## Запуск

```sh
docker compose up -d --build
```

Открыть `http://localhost:8095` или `http://<IP сервера>:8095` с другой машины.
`N5_PORT` меняет порт, `N5_HOST=127.0.0.1` ограничивает доступ текущим компьютером.

## Словарь

Стартовый экран «Моё обучение» предлагает следующий урок с 10 заданиями,
повторение по расписанию или продолжение сохранённого занятия. Смешанная
тренировка доступна отдельной ссылкой. Второстепенные пункты меню раскрываются
внутри разделов; текущий раздел открывается автоматически. В подготовке выбор
тем и длительности раскрывается отдельно.
В меню «Курс N5» находятся отдельные страницы «Уроки 1–25» и «Повторение по урокам».
Выбор урока, длительность и запуск занятия доступны перед правилами;
после правил есть повторная кнопка запуска.
Карта материала и официальные источники
описаны в [покрытии программы](docs/n5-curriculum.md).
После каждого пятого урока доступно повторение блока: 1–5, 6–10, 11–15,
16–20 и 21–25. Задания распределяются между пятью уроками; результаты по каждому
уроку и история повторений сохраняются в браузере.
После каждого пятого урока доступно повторение с вопросами из всех пяти уроков,
результатом по каждому уроку и сохранением истории.
В «Словах и формах» новые занятия по умолчанию содержат 10 заданий; свободный режим
доступен в настройках.

Встроенные слова имеют русские и английские значения; поиск работает по обоим
языкам, написанию и чтению. Русские переводы добавляются в сохранённый словарь
при обновлении, если исходное значение не изменялось; собственные переводы сохраняются.

Кнопка «Добавить слово» открывает форму. Поля со звёздочкой обязательны; группа зависит от раздела. Новое слово также появляется в общем словаре.
Ромадзи заполняется из кана автоматически и допускает ручную правку. Русский перевод
для собственного слова необязателен.

В Docker словарь хранится в volume `vocabulary`, файл `/app/storage/vocabulary.json`. При первом запуске он заполняется из встроенного словаря. Перезапуск и пересборка сохраняют изменения; `docker compose down -v` удаляет volume. Последующие обновления встроенного словаря не перезаписывают сохранённый.

Без Docker:

```sh
python server.py
```

По умолчанию используются `127.0.0.1:8095` и `data/vocabulary.json`. Переменные `HOST`, `PORT`, `N5_VOCABULARY` меняют адрес и путь к словарю.

## Глаголы в сочетаниях

В меню «Курс N5» → «Глаголы в сочетаниях» доступно изучение 170 глагольных
записей: сочетание, чтение, русский перевод, значение глагола и пояснение к частице.
Разные значения одинаковых слов имеют отдельные карточки. Есть темы, поиск,
связанные сочетания для сравнения и отметки «Учу» / «Знаю», сохраняемые в браузере.
Дополнительные глаголы за пределами N5 вынесены в отдельную тему.

После изучения можно закрепить выбранные карточки: дополнить глагол или написать
сочетание целиком каной, кандзи либо через ввод ромадзи. Занятие содержит до 10
заданий; ошибки и показ ответа возвращают карточку в «Учу». По умолчанию тренировка
использует только отмеченные карточки. Результат занятия показывает первую попытку.
Из строки глагола в словаре можно сразу открыть его сочетание.

Материал находится в `data/verb-phrases.json`. Раздел показывает покрытие текущего
словаря и список добавленных или изменённых глаголов, для которых сочетаний ещё нет.

## Синонимы и антонимы

В меню «Курс N5» → «Синонимы и антонимы» доступны 76 связок: 33 пары
антонимов, 10 пар близких по значению слов и 33 перефразирования через отрицание.
Карточки содержат чтение, переводы, контекст и пояснения к различиям. Например,
«тёмный ≈ не светлый» выделено в отдельный тип, а не объявлено точным равенством.
Высота и цена у 高い, время и скорость у 遅い изучаются в разных контекстах.

Можно искать связки, выбирать тип связи и статус, отмечать «Учу» / «Знаю»
и тренировать изученные пары занятиями до 10 заданий. Лексические пары спрашиваются
в обоих направлениях; перефразирование требует отрицания указанного слова.
Отметки и последняя карточка сохраняются в браузере. Ошибки и подсказки возвращают
связку в «Учу»; результат учитывает первую попытку. Данные: `data/word-relations.json`.

## Фуригана

В текстовых разделах чтение показано над кандзи с помощью ruby: в словаре,
карточках сочетаний и связей слов, тренировках форм и грамматики, справках,
текстах для чтения и разборах ответов. Для карточек используются их явные чтения;
для остального текста — сохранённый словарь и проверенные формы слов.
Окуригана и частицы остаются на основной строке. Неоднозначные и неизвестные
чтения автоматически не угадываются. Отдельные строки чтения также сохранены.

В заданиях на чтение кандзи и выбор написания фуригана скрыта до проверки;
в письменном пробнике — до разбора. Исходные PDF, сканы и изображения сохраняют
оригинальную печатную фуригану, приложение не дорисовывает её на страницы.

## Проверки

GitHub Actions → **Release builds** собирает Android ARM64, Linux x86-64/ARM64 и
Windows x86-64. Ручной запуск сохраняет файлы в Artifacts; отправка тега `v…`
собирает все платформы и прикладывает архивы, APK и SHA-256 к GitHub Release.
Для APK один раз задай Secrets: `N5_KEYSTORE_BASE64`, `N5_STORE_PASSWORD`,
`N5_KEY_ALIAS`, `N5_KEY_PASSWORD`. Используй прежний ключ подписи, чтобы APK
устанавливался поверх существующего приложения. Ключ в Git не добавляется.
Пошаговая [настройка подписи в GitHub Actions](android/README.md#github-actions).

Настольный архив нужно распаковать целиком и запустить `n5-local` или
`n5-local.exe`. Интерфейс откроется в браузере, Python устанавливать не нужно.
Окно запуска остаётся открытым до завершения работы (Ctrl+C). Словарь хранится
отдельно: `%LOCALAPPDATA%/N5Local` в Windows и
`${XDG_DATA_HOME:-~/.local/share}/n5-local` в Linux. Адрес остаётся
`http://127.0.0.1:8095`, поэтому прогресс браузера сохраняется при обновлении.

Ручное обновление Docker и сборка APK одной командой описаны в
[docs/automation.md](docs/automation.md).

```sh
python -m n5.vocabulary validate
python -m unittest -q test_server.py test_repository.py test_store.py
npm run test:forms
npm run test:ui
```

Для браузерных тестов нужны Playwright и Chromium: `npm install`, `npx playwright install chromium`.

Библиотека Tadoku использует оригинальные файлы из `data/materials/tadoku/files`, подключённые в Docker отдельно от образа. Восстановить недостающие файлы выбранного каталога:

```sh
python scripts/import_tadoku.py --download
```

Книги открываются с непрерывной вертикальной прокруткой. Доступны увеличение двумя
пальцами, кнопки масштаба до 400%, режимы «По ширине» и «Страница целиком», миниатюры
и полноэкранное чтение. Позиция внутри страницы, масштаб и место в аудио сохраняются
для каждой книги. Плеер закреплён под страницами; перемотка — по 10 секунд.
Авторы, лицензии, оригинальные PDF и отметка «Прочитано» доступны через «О книге».
Нумерация соответствует страницам PDF, включая обложки и служебные страницы.
Импорт обновляет этот счётчик при наличии `pdfinfo` (Poppler). Поиск и выделение
текста в просмотрщике не включены.

PDF сохраняются без изменений с авторством и CC BY-NC-ND 4.0. У аудио отдельно записаны источник, чтец и правообладатель; официальные загрузки предназначены для личного учебного прослушивания, а не для публичного переиздания.

Весь `data/materials/` включён в Git: Tadoku, Sō-matome и экзаменационные варианты вместе с PDF, изображениями, аудио и разметкой. После клонирования репозитория отдельное скачивание материалов не требуется. Git LFS не используется. В Docker папка подключается только для чтения и не копируется в образ; `N5_MATERIALS_DIR` меняет её путь. APK включает материалы при сборке. Условия использования и авторство сохраняются в каталогах источников.

Экзаменационные варианты находятся в `data/materials/jlpt/<набор>/` (`exam.json`, `images/`, `audio/`). Для повторного импорта из исходных PDF/OPUS можно использовать `python scripts/import_exams.py --source <исходники> --manifest <exam.json> --destination data/materials/jlpt/<набор>`; нужны Poppler, Pillow и ffprobe. Обычная сборка использует готовые изображения из Git.

## Аудио без заданий

Раздел «Аудио» доступен прямо из основного меню. Он объединяет доступные полные
экзаменационные записи, дорожки Sō-matome и озвученные книги Tadoku. Выберите
источник и нажмите «Слушать подряд» либо начните с нужной записи. Очередь идёт
по порядку без ответов и таймера; на последней записи останавливается, если не
включён повтор очереди. Записи, не сопоставленные с заданиями варианта, помечены.

Доступны пауза, предыдущая/следующая запись, перемотка на 15 секунд, выбор
позиции и скорость 0,75–1,5×. Очередь и позиция каждой записи сохраняются отдельно
от результатов занятий. После повторного открытия нажмите «Слушать» для
продолжения. При переходах внутри приложения запись не прерывается: внизу
появляется компактный плеер. Запуск аудио упражнения ставит общий плеер на паузу.

В браузере используются системные медиакнопки, если браузер поддерживает Media
Session; вкладку нужно оставить открытой. В Android-приложении аудио раздела
играет через отдельный foreground-сервис с уведомлением и MediaSession,
независимо от WebView и состояния экрана. При потере аудиофокуса и отключении
наушников воспроизведение приостанавливается. Для работы на телефоне требуется
APK, собранный из версии с этим сервисом.

### Превью книг и учебный интерфейс

Каталог показывает первую страницу каждой книги; миниатюры входят в приложение
и не требуют загрузки полного PDF. После обновления исходных книг пересоздайте
их командой `python scripts/build_book_covers.py` (нужны Poppler и Pillow только
на машине сборки).

В учебных разделах правила, примеры и примечания разделены; результат проверки
появляется перед кнопками и прокручивается в видимую область. В заданиях без
ключей ответ сохраняется без оценки. Дополнительные настройки читалки на
телефоне открываются кнопкой «Параметры». Для новых слов достаточно русского
или английского перевода.

### Учебный процесс и общий прогресс

Навигация разделена по задачам: учиться, повторять, проверить знания, читать,
найти слово или правило, слушать. В уроке сначала показаны правила, затем запуск
практики. После проверки варианты получают явные состояния ошибки и верного
ответа; основной следующий шаг заменяет проверку.

В словаре группы раскрываются по запросу; действия под словом всегда видимы и
оформлены компактно. В библиотеке
фильтры свёрнуты по умолчанию. Вспомогательные инструкции ввода находятся в
«Помощь с ответом». Новые пользователи могут начать тренировку сочетаний без
предварительных отметок.

Главная и подробные результаты читают существующие локальные сохранения всех
учебных разделов: показывают реальные позиции продолжения, отдельные результаты,
повторение и его ближайший срок. Общий процент готовности к JLPT не вычисляется.
Ссылки продолжения учебников и экзаменационных вариантов сразу открывают
сохранённое занятие; черновики и схемы хранилищ сохраняются.
