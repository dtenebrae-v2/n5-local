# Ручная сборка APK и обновление Docker

Из корня проекта:

```sh
python3 scripts/release.py
```

Скрипт использует текущее содержимое рабочей папки, включая незакоммиченные
изменения. Обновлять код из GitHub и создавать коммит перед сборкой не требуется.
Сборка запускается только этой командой; таймер отключён.

## Что выполняется

1. Проверка словаря, Python-тесты, тесты форм и браузерные сценарии.
2. Сборка ARM64 APK со всеми локальными книгами, аудио и остальными материалами.
3. Android Lint, проверка офлайн-сервера, всех медиафайлов, содержимого APK,
   подписи и выравнивания.
4. Сборка Docker-образа и сохранение APK с контрольной суммой.
5. Обновление контейнера с ожиданием `healthy`. При ошибке — попытка вернуть
   предыдущий Docker-образ. Volume словаря и каталог материалов сохраняются.
6. Переключение `dist/latest` на успешный выпуск. Сохраняются два последних
   успешных APK и текущий/предыдущий Docker-образы этого скрипта.

Параллельные выпуски блокируются файловым lock. Если проверка или сборка
завершается ошибкой, до этапа обновления действующий контейнер продолжает работать.

## Результат

Готовый APK: `dist/latest/n5-local-arm64.apk`.
Рядом находятся SHA-256, `release.json` и `success.json`.
Последний успешный выпуск также записан в `.automation/last-success.json`.

## Инструменты

Если JDK, Android SDK и Gradle установлены в `.build-tools/`, скрипт находит
их автоматически. Переменные `JAVA_HOME`, `ANDROID_HOME`,
`GRADLE_USER_HOME` и `N5_GRADLE`, заданные вручную, имеют приоритет.

Для другой машины нужны Docker Compose с поддержкой `up --wait`, Git, Node.js/npm,
Python 3.11+ и Playwright (`npm install`, Chromium либо `BROWSER_PATH`). Для Android:
JDK 17, SDK platform 35 и build-tools 35.0.0. Gradle 8.11.1 загружает wrapper.
Python 3.14 рекомендуется для предварительной компиляции кода Chaquopy.

Весь каталог `data/materials` с книгами и аудио входит в Git и переносится при клонировании.
Сохрани также ключ подписи `~/.android/debug.keystore`: он нужен для установки
новых APK поверх старых с сохранением данных. Номер Android-версии генерируется
по времени выпуска. Готовые APK исключены из Git.
